# Конфигурация виртуальной машины devops-vm

## 1. Параметры машины
- **Оперативная память (RAM):** 2048 МБ (2 ГБ)
- **Количество ядер процессора:** 2 vCPU
- **Объём дискового накопителя:** 25 ГБ, динамически расширяемый
- **Гипервизор:** Oracle VM VirtualBox 7.x
- **Операционная система:** Ubuntu Server 24.04 LTS (ARM 64-bit)

## 2. Сетевые интерфейсы
- **Сетевой адаптер 1 (`enp0s3` / `enp0s8`):**
  - **Тип адаптера:** NAT
  - **Полученный IP-адрес:** `10.0.2.15/24`
  - **Назначение:** Обеспечение исходящего доступа виртуальной машины в сеть Интернет (загрузка и обновление пакетов), а также организация управляющего SSH-доступа через проброс портов гипервизора.
- **Сетевой адаптер 2 (`enp0s8` / `enp0s9`):**
  - **Тип адаптера:** Виртуальная сеть хоста (Host-only Network, `vboxnet0`)
  - **Полученный IP-адрес:** `192.168.56.2/24`
  - **Назначение:** Прямая изолированная сетевая связность между хостовой системой (macOS, IP `192.168.56.1`) и гостевой ОС. Используется для прямого обращения по локальному доменному имени `devops.local` и доступа к веб-серверу в практической работе № 6.

## 3. Правило проброса портов
- **Наименование правила:** `ssh`
- **Протокол:** TCP
- **Адрес хостовой системы:** `127.0.0.1`
- **Порт хостовой системы:** `2222`
- **Адрес гостевой системы:** (не заполняется / `0.0.0.0`)
- **Порт гостевой системы:** `2222` (перенастроен со стандартного 22 в процессе харденинга службы SSH)

## 4. Учётные записи
- **`student`**:
  - **UID:** 1000
  - **Принадлежность к группам:** `student`, `adm`, `sudo`
  - **Способ аутентификации:** Парольная аутентификация (установлена на этапе инсталляции ОС).
- **`devops`**:
  - **UID:** 1001
  - **Принадлежность к группам:** `devops`, `sudo`
  - **Способ аутентификации:** Исключительно по открытому ключу SSH (алгоритм ED25519, открытый ключ размещён в `~/.ssh/authorized_keys`).

## 5. Служба SSH
- **Порт службы:** `2222`
- **Расположение файлов конфигурации:**
  - Базовый файл: `/etc/ssh/sshd_config` (сохранена резервная копия `/etc/ssh/sshd_config.backup`)
  - Файл усиления защиты (hardening): `/etc/ssh/sshd_config.d/99-hardening.conf`
- **Изменённые директивы и их значения:**
  - `Port 2222` — нестандартный порт для минимизации фонового автоматизированного сканирования ботами;
  - `PermitRootLogin no` — запрет прямого входа от имени суперпользователя `root`;
  - `PasswordAuthentication no` — отключение парольной аутентификации в пользу ключевой;
  - `PubkeyAuthentication yes` — разрешение аутентификации по криптографическим ключам;
  - `PermitEmptyPasswords no` — запрет авторизации учетных записей без паролей;
  - `MaxAuthTries 3` — ограничение числа неуспешных попыток авторизации в рамках одной сессии;
  - `LoginGraceTime 30` — ограничение времени на завершение аутентификации (30 секунд);
  - `AllowUsers devops` — ограничение списка пользователей, которым разрешено инициировать SSH-сессию;
  - `X11Forwarding no` — отключение форвардинга графической подсистемы X11;
  - `ClientAliveInterval 300` и `ClientAliveCountMax 2` — контроль тайм-аута неактивных сессий.
- **Особенности конфигурации дистрибутива:**
  - Отключена активация через сокет `systemctl disable --now ssh.socket`, служба переведена на постоянный сервис `systemctl enable --now ssh.service` для корректного применения директивы `Port 2222`.
  - В файле `/etc/ssh/sshd_config.d/50-cloud-init.conf` закомментирована директива `PasswordAuthentication yes`, предотвращая переопределение настроек безопасности.

## 6. Правила межсетевого экрана
- **Политики по умолчанию:**
  - `Default incoming policy`: `deny` (запрещены любые входящие соединения, кроме явно разрешённых);
  - `Default outgoing policy`: `allow` (исходящий трафик сервера не ограничивается);
  - `Routed`: `disabled`.
- **Перечень активных правил (UFW):**
  - `2222/tcp (v4 & v6)` — `LIMIT IN` (входящие подключения SSH с ограничением частоты: не более 6 попыток соединения за 30 секунд);
  - `80/tcp (v4 & v6)` — `ALLOW IN` (HTTP-трафик для будущего веб-сервера);
  - `443/tcp (v4 & v6)` — `ALLOW IN` (HTTPS-трафик для защищённого веб-сервера).

## 7. Снимки состояния
1. **`01-clean-install`** — чистая установка Ubuntu Server 24.04 LTS, первое обновление пакетов системы (`apt update && apt upgrade`) и первичная фиксация сетевых интерфейсов.
2. **`02-keys-configured`** — создана учетная запись `devops`, добавлен в `sudo`, сгенерирована пара ключей ED25519, настроен клиентский алиас в `~/.ssh/config` и проверен вход по ключу без пароля.
3. **`03-ssh-hardened`** — выполнен полный харденинг SSH (отключение root, отключение паролей, смена порта на 2222, отключение сокета `ssh.socket`), обновлён проброс портов в VirtualBox, проверена фиксация отклоненных попыток в системном журнале.
